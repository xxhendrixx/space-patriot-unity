# Rifle aim-down-sights asset

Generated with the built-in image generation tool, using `assets/ui/rifle-view-v10.png` as the identity reference. Final asset: `assets/ui/rifle-ads-v11.png`. The image generator returned an opaque checkerboard for the first two transparency requests, so the production file uses a chroma backdrop. The weapon sprite material removes that backdrop once at decode, including the sight aperture; the original authored PNG is retained unchanged.

## Initial generation prompt

Use case: stylized-concept. Asset type: production first-person weapon aim-down-sights overlay for the game Space Patriot. The input is a reference for the SAME weathered gunmetal rifle, rectangular open holographic optic, black tactical gloves and segmented gray armored forearms. Create the AIM-DOWN-SIGHTS view of this same rifle, camera directly behind and looking straight along its barrel, completely centered and symmetric in perspective instead of the oblique hip-fire view. Output one high-detail landscape 1536x1024 PNG with a genuinely transparent alpha background. The open optic aperture must also be genuinely transparent, with no glass tint or painted background and no baked reticle. The optical sight aperture center must be exactly at canvas pixel (768, 430). Rear optic housing is clearly visible framing that open aperture; barrel and rail converge exactly beneath that center. Weapon receiver and gloved hands occupy the lower center of the canvas and run off the bottom edge; the top half and side space remain completely transparent. Show no landscape, no target, no scenery, no text, no muzzle flash. Preserve the reference weapon identity, realistic wear and lighting, high-quality authored game concept rendering. No lateral cant: straight level true ADS alignment. Critical: genuine transparent background and transparent optic hole, not a green-screen or checkerboard painting.

## Transparency repair attempt

Use case: background-extraction. Make this exact weapon image a production transparent PNG cutout. The current gray and white checkerboard is incorrectly painted into RGB pixels. Remove EVERY checkerboard background pixel, including ALL checkerboard visible THROUGH the open sight aperture. Replace those pixels with true alpha zero transparency. Preserve the rifle, gloves, forearms, optic housing, object position, canvas size 1536x1024 and every material detail exactly. Do not redraw or reposition the gun. Do not create any checkerboard pattern, solid background, scenery or reticle. The output file must have an RGBA alpha channel, with actual alpha 0 for the background and the open sight aperture. A painted checkerboard is not acceptable.

## Final production prompt

Use case: precise-object-edit. Preserve the gun, gloves, optic housing, all object contours, camera angle, size, exact position and 1536x1024 canvas from this input unchanged. Change only the entire gray-white checkerboard background to uniform flat chroma green RGB (0,255,0), including every pixel of background visible through the open optic aperture. Pure solid #00FF00 only for the backdrop: no checkerboard, no gradients, no green light spilling on the gun, no shadows on the green. The gray metal weapon must remain exactly the same natural gray/brown colors. This is a game sprite on a color-key backdrop for a runtime transparency shader, so the green background must be absolutely flat.

The actual aperture is calibrated at (768,420). The red dot remains live at the viewport center; it is not baked into the asset. The muzzle effect uses the supplied Spellworks particle shader and a separate world-space point light.
