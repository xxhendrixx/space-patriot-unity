# Original engines in the Unity restoration

This is an unfinished restoration. Preserving source files is different from running their behavior in Unity. The original HTML engines and runtime exports remain in `Reference/Original`; the table below describes actual integration.

| Engine | Runs in this version | Still missing |
| --- | --- | --- |
| Worldworks / Terrainworks | Build tools execute the original JavaScript cores for 13 solid-world height, moisture, temperature and rock fields, using the source game's per-world seeds, biome families and humidity values. Unity samples each field into a closed planet and rebuilds a player-centered 12 km surface patch at the source renderer's 96 flight / 192 walking segment density. The patch recenters every 1.2 km in flight or 120 m on foot and samples the same Unity height query used for grounding. Seeded, biome-scaled macro relief continues across the rest of each solid planet. | The moving patch restores HTML-style surface coverage, but terrain beyond the active source field still uses lower-resolution macro relief. Existing planet collision and height queries remain authoritative; the render patch has no separate collider. Seamless global field detail, complete climate profiles and surface gravity remain missing. |
| Grassworks | Native five-segment grass blades, terrain rooting, original wind equations, stable nearby tiles and distance/altitude culling. | Full biome population, far-field vegetation and desktop performance tuning. |
| Spellworks | Bounded native effect pools render through the active Unity game camera. Weapon impacts, explosions, muzzle flashes and survey scans emit gameplay-linked particles with the ported lifetime/drag/gravity/turbulence behavior. | The original eight configurable effect presets, branching lightning/beam variants, full debris pool and authored effect combinations are not all ported. The current effects remain a small subset of the original visual system. |
| Oceanworks | Curved local water surface with directional waves, swell, crest foam and time-varying normals. | Full reflections, wave breaking and global oceans. |
| Weatherworks | Native wetness, snow, gust equations, precipitation near the player and roof occlusion. Ground materials respond to wetness and snow. | Original cloud fronts, lightning and complete weather/climate simulation. |
| Fireworks | Flame lifecycle, buoyancy, taper, turbulence and heat gradient used for nearby wreck impacts. Six finite emitter slots are recycled. | All original fire, ember and smoke stages. Smoke currently uses Spellworks. |
| Architectureworks | Original furnished buildings and lifts; seven connected service districts, street blocks and 420 named regional destinations with persistent state. | Bespoke cities, complete tower interiors and seamless global placement. |
| Machineworks | Native vessel power/component state and working hangar lift/roof mechanisms. | Complete original machine graph and dependencies. |
| Storyworks | Nine cases and 27 objective gates/rewards connected to the campaign. | Full original 90-node graph interpreter and event parity. |
| Inventoryworks | Cargo handling with settlement-specific dock stock; field inventory, weight limits, original ammo/repair/sample recipes and named NPC exchanges. | Complete equipment and consumable parity. |
| Pathworks | Native street itineraries for residents, job/needs-driven schedules and owned NPC vessel routes. Original source remains preserved. | General obstacle-aware path planning, crowd avoidance and full original graph parity. |
| Creatureworks | Original alien plant models imported. | Articulated creatures, locomotion, IK and body-part damage. |
| Audio | Procedural reactor/pump ambience, coil discharge, guarded relay click and hull impact use layered tones, transients and envelopes; engine load follows flight state. | Sound quality is still below the original game's needs: there is no authored sound library, positional exterior engine/exhaust mix, spatial world audio or full environmental soundscape. This needs a dedicated sound pass. |

The visible city is also still much smaller than the source-world data suggests: seven service districts and their shared street spine are built around the current port. The 420 destination names and resident records do not mean 420 cities are present in the scene. Planet-scale settlement placement and varied distant skylines remain work to do. The active surface now streams a 12 km render patch as the player moves, but this does not yet stream complete city regions or the full-resolution source terrain fields.

The refitted fleet uses ten distinct chassis with original dimensions, finishes, atlas textures and preserved interiors. The asset pipeline is in `Tools/AssetPipeline`. This is a first visual revision, not a finished art pass.

`Validation/engine-restoration.txt` covers terrain continuity, walking/mesh agreement, bounded grass/effect populations and integrated runtime components. `Validation/world-streaming.txt` checks the player-centered patch resolution, recentering, height-query agreement and collision ownership. Input checks use synthetic Unity Input System devices. Physical controller feel, complete missions and sustained desktop performance still require testing.

The society simulation, community jobs, original named exchanges, multideck layouts and Blender art source are documented in [design and implementation notes](ArtDirection/DESIGN_AND_IMPLEMENTATION.md).
